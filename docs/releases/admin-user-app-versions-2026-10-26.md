## 保持の事前確認と限界

- `LocationHomeScreen.handleSignOut`は記録／共有中のサインアウトを拒否。通常サインアウトは保存済みサーバー記録・SQLiteキューを削除しない。
- `App.tsx`のsignedOut処理と`singleDeviceSessionService.clearLocalDeviceSessionRegistration`は認証関連登録を解除し、SQLite／AsyncStorage全消去は行わない。
- `locationLocationQueueService.getPendingLocationQueueRows`はuser_id・recording_session_idで送信候補を分離。
- コード読取と過去の検証104の合成pending試験は、今回の通常版の非ゼロ実未送信データの直接保持証明ではない。
- 今回OTAで保存／破棄／再送／停止後復旧／背景記録／現在地共有の全回帰を再実施していない。内蔵版等の過去合格は対象SHA・OTAを維持して記載する。
