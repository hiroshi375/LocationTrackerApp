プライバシーポリシー

AcLog Fit（以下「本アプリ」といいます。）では、 ユーザーの移動履歴を記録・表示・共有するために、 位置情報などの情報を取り扱います。 本ポリシーでは、取得する情報とその利用方法について説明します。

1. 取得する情報

本アプリでは、サービスの提供に必要な範囲で、次の情報を取得または保存する場合があります。 ・位置情報（緯度、経度、取得時刻、位置精度など） ・位置情報の取得元（foreground / background） ・移動距離、移動時間、アクティビティ区分などの記録情報 ・バッテリー残量、バッテリー状態、省電力モードなど、位置記録の状況確認に必要な情報 ・ユーザーID、メールアドレス、表示名 ・消費カロリーの目安を算出するため、ユーザーが任意に登録した体重（kg） ・ユーザーが登録したプロフィール画像 ・共有グループ、共有先ユーザーなどの共有設定 ・アクティビティランキングや利用状況を算出するための集計情報 ・FREE / PREMIUMの利用状態および購入状態 ・アプリの動作状況、エラー、処理結果などの診断情報 ・端末セッションの管理に使用する、本アプリが生成した端末識別子 ・アプリのバージョン、ビルド番号、OS種別、最終起動日時 ・地図表示サービスが取得するSDK識別子、IPアドレス、端末・OSに関する情報、地図操作情報、クラッシュ・診断情報（利用するSDKと設定により異なります）

2. 情報の利用目的

取得した情報は、主に次の目的で利用します。 ・移動ルートおよびアクティビティ履歴の記録・表示 ・移動距離、移動時間などの算出 ・アクティビティ区分の判定 ・登録された体重とアクティビティ情報に基づく消費カロリーの目安の算出 ・リアルタイム位置情報およびアクティビティ履歴の共有 ・アクティビティランキングおよび活動実績の集計 ・FREE / PREMIUMの機能制御 ・購入済みPremium機能の確認および復元 ・不具合調査、サービス改善、安定運用 ・不正利用やサービスの不適切な利用の防止 ・端末セッションの管理、アプリのバージョンおよび利用状況の確認

3. バックグラウンドでの位置情報取得

本アプリでは、自動記録機能を提供するため、ユーザーが記録を開始している間、アプリが画面に表示されていない場合や使用していない間にも位置情報を取得する場合があります。取得した情報は、移動ルートおよびアクティビティ履歴の継続記録に利用します。 位置情報の取得には、端末の設定で必要な権限を許可する必要があります。権限はiOS・Androidの端末設定から変更または取り消すことができます。権限を取り消すと、位置情報を使用する機能の一部または全部が利用できなくなる場合があります。 位置情報の取得権限の変更は、すでに保存したアクティビティ履歴の削除とは異なります。保存済みデータについては「9. 情報の保存期間と削除」をご確認ください。

4. 情報の保存

取得した位置情報、アクティビティ履歴、プロフィール情報などは、サービス提供のため、AWS（Amazon Web Services）のクラウドサービス等を利用して保存します。 一部の設定情報、未送信の位置記録データなどは、アプリがインストールされた端末内に保存される場合があります。通信状態によってはクラウドへの反映が遅れる場合があります。 情報の保存期間と削除方法については「9. 情報の保存期間と削除」をご確認ください。

5. 外部サービスの利用

本アプリでは、サービス提供のために次の外部サービスを利用しています。 ・AWS：ユーザー認証、データ保存、API等 ・RevenueCat：Premiumの購入状態および利用権限の確認 ・Apple App Store / Google Play：Premium商品の購入処理 ・Google Maps / Appleマップ：地図表示 これらのサービスでは、サービス提供に必要な情報が各事業者によって処理される場合があります。情報の取扱いには各事業者のプライバシーポリシー等が適用される場合があります。また、サービスのシステムやデータセンターの所在地により、情報が日本国外で処理または保存される場合があります。 RevenueCatには、購入状態の確認・復元や利用権限の管理のため、本アプリのユーザー識別子と購入に関する情報が送信されます。購入に関する情報は、RevenueCatのダッシュボード等で購入状況を把握・分析するためにも利用されます。本アプリからRevenueCatへ、位置情報、体重、プロフィール画像を購入者属性として送信する処理は行っていません。 Google Maps等の地図表示サービスでは、地図の提供、利用状況の把握、安定性およびサービス品質の改善のため、SDK識別子、IPアドレス、端末・OSに関する情報、地図の移動・拡大縮小等の操作情報、クラッシュ・診断情報が取得される場合があります。取得項目と処理方法は、利用するSDK、OS、設定および各事業者の方針により異なります。

6. Premium購入に関する情報

Premium商品の購入処理はApple App Store / Google Playを通じて行われます。 本アプリがクレジットカード番号などの決済情報を直接取得することはありません。 本アプリでは、Premium機能を提供するため、 RevenueCatを通じて購入状態やPremium利用権限を確認します。 RevenueCatでの購入状態の確認は、本アプリのユーザー識別子に関連付けて行います。購入に関する情報は、Premium機能の提供・不正利用の防止に加え、購入状況の把握・分析にも利用されます。

7. ユーザー間での情報共有

【リアルタイム位置情報の共有】 ユーザーが位置共有の相手を選択し、共有を有効にした場合、現在地、取得・更新時刻などが共有相手に表示されます。アクティビティ履歴の共有とは別に、位置共有の設定を確認してください。 【アクティビティ履歴の共有】 グループへの参加だけで、過去のアクティビティ履歴が共有されることはありません。記録の所有者が、アクティビティ履歴ごとに共有相手と共有に使用するグループを指定します。共有されたアクティビティ履歴およびその地図・位置記録は、所有者と有効な共有権限を持つ相手が閲覧できます。アクティビティカレンダーには、ログイン中のユーザー本人が所有するアクティビティ履歴だけが表示されます。他のユーザーから共有されたアクティビティ履歴は、アクティビティカレンダーには表示されません。 共有解除、脱退、除外、グループの無効化・削除などによって対象の共有権限が失効すると、その相手は対象アクティビティ履歴や位置記録をサーバーから新たに取得できなくなります。ただし、別のグループを通じた有効な共有が残っている場合は、引き続き閲覧できます。グループへの再参加だけでは失効した共有は復活せず、所有者による再共有が必要です。記録の所有者本人の閲覧権限は、グループからの脱退・除外やグループ削除によって失われません。 【共有に伴う表示と注意】 「履歴の共有管理」画面や「共有グループ管理」画面などでは、相手を識別するために表示名、メールアドレス、プロフィール画像などを表示する場合があります。アクティビティランキングで表示される情報については「8. アクティビティランキング」をご確認ください。共有終了前に端末へ取得された情報や、共有相手が保存した画像・コピーまで消去できるとは限りません。 位置情報や移動履歴から自宅、勤務先、生活時間帯などが推測される場合があります。信頼できる相手と共有してください。他のユーザーから共有された情報を本人の同意なく第三者に公開しないでください。

8. アクティビティランキング

アクティビティランキング機能では、表示名、プロフィール画像、対象となるアクティビティの移動距離、移動時間など、アクティビティランキング表示に必要な情報が、アクティビティランキングを閲覧できる他のユーザーに表示される場合があります。 アクティビティランキングには、本アプリが定める集計条件を満たすアクティビティのみが反映されます。操作説明用のサンプルアクティビティは集計対象になりません。

9. 情報の保存期間と削除

ユーザー情報およびアクティビティ履歴は、原則としてアカウントまたは対象データが存在する間保存されます。 位置情報の取得権限は端末設定から変更・取り消しができます。これは今後の取得を制御する操作であり、保存済みアクティビティ履歴の削除とは異なります。記録の停止、共有の解除、保存済み情報の削除は、それぞれ対応する機能で行ってください。保存済みのアクティビティ履歴は、本アプリの「アクティビティ履歴」画面の「削除」機能から削除できます。 アカウント削除機能では、共有権限を失効させたうえで、位置記録、アクティビティ履歴、現在地情報、共有Grant、関連する共有操作情報、索引、月間・週次集計、記録診断情報、端末セッション、プロフィール画像、プロフィールおよび認証アカウントを順に削除します。ユーザーが所有する共有グループは削除し、他のグループからは脱退します。他のユーザーが所有するアクティビティ履歴は削除せず、対象となる共有権限を解除します。 この端末に保存された削除対象ユーザーの未送信記録も削除します。他のアカウントの未送信記録は削除しません。別の端末に保存された情報や共有相手が既に保存した画像・コピーまで、遠隔で消去できるとは限りません。 処理に時間がかかる場合は小分けにして進めます。通信断やアプリ終了などで中断した場合は、アカウント削除を再実行して続きから再開してください。エラーが表示された場合は、削除が完了したと判断せず、再実行するかお問い合わせください。 再開と重複実行防止のため、必要最小限の削除進捗情報を保持します。サーバー上の関連データの削除処理が完了した後、この進捗情報は7日を目安として自動削除処理の対象になります。 上記の記録診断情報とは別に、共有管理サーバーの共用運用ログには、処理時刻、ユーザー識別子、エラーなどが記録される場合があります。この共用運用ログは通常のアカウント削除の対象外です。現行の設定では保存期間の上限を設けていません。 法令により保持が必要な情報がある場合は、その目的に必要な範囲と期間に限って保持します。削除対象・方法・処理状況については「13. お問い合わせ」からご連絡ください。

10. 安全管理

本アプリでは、取得した情報への不正アクセス、 紛失、漏えい、改ざん等を防止するため、 利用するクラウドサービスのセキュリティ機能などを活用し、 合理的な安全管理措置を講じるよう努めます。

11. 未成年者の利用

未成年の方が本アプリを利用する場合は、 必要に応じて保護者等の同意を得たうえで利用してください。 特に位置情報の共有機能を利用する場合は、 共有する相手や共有範囲を十分に確認してください。

12. プライバシーポリシーの変更

本アプリの機能変更、法令の変更その他の事情により、本ポリシーを変更する場合があります。重要な変更については、変更内容と適用時期をアプリ内その他適切な方法でお知らせします。 既に取得した情報の利用目的や共有範囲を拡大・変更する場合は、その内容を説明し、変更後の利用を開始する前に必要な同意を取得します。適用される法令およびプラットフォームの要件に従います。 同意の再確認が必要な改定では、以前に同意したユーザーにも改定後の文書を案内し、再度確認・同意を求めます。
