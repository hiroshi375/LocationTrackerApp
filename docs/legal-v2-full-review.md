# プライバシーポリシー

AcLog Fit（以下「本アプリ」といいます。）では、 ユーザーの移動履歴を記録・表示・共有するために、 位置情報などの情報を取り扱います。 本ポリシーでは、取得する情報とその利用方法について説明します。

最終改定日（案）：2026年10月19日


## 1. 取得する情報 【変更】

本アプリでは、サービスの提供に必要な範囲で、次の情報を取得または保存する場合があります。

・位置情報（緯度、経度、取得時刻、位置精度など）
・位置情報の取得元（foreground / background）
・移動距離、移動時間、アクティビティ区分などの記録情報
・バッテリー残量、バッテリー状態、省電力モードなど、位置記録の状況確認に必要な情報
・ユーザーID、メールアドレス、表示名
・ユーザーが登録したプロフィール画像
・共有グループ、共有先ユーザーなどの共有設定
・アクティビティランキングや利用状況を算出するための集計情報
・FREE / PREMIUMの利用状態および購入状態
・アプリの動作状況、エラー、処理結果などの診断情報


## 2. 情報の利用目的 【変更】

取得した情報は、主に次の目的で利用します。

・移動ルートおよびアクティビティ履歴の記録・表示
・移動距離、移動時間などの算出
・アクティビティ区分の判定
・リアルタイム位置情報およびアクティビティ履歴の共有
・アクティビティランキングおよび活動実績の集計
・FREE / PREMIUMの機能制御
・購入済みPremium機能の確認および復元
・不具合調査、サービス改善、安定運用
・不正利用やサービスの不適切な利用の防止


## 3. バックグラウンドでの位置情報取得 【変更】

本アプリでは、自動記録機能を提供するため、ユーザーが記録を開始している間、アプリが画面に表示されていない場合や使用していない間にも位置情報を取得する場合があります。取得した情報は、移動ルートおよびアクティビティ履歴の継続記録に利用します。

位置情報の取得には、端末の設定で必要な権限を許可する必要があります。権限はiOS・Androidの端末設定から変更または取り消すことができます。権限を取り消すと、位置情報を使用する機能の一部または全部が利用できなくなる場合があります。

位置情報の取得権限の変更は、すでに保存したアクティビティ履歴の削除とは異なります。保存済みデータについては「9. 情報の保存期間と削除」をご確認ください。


## 4. 情報の保存 【変更】

取得した位置情報、アクティビティ履歴、プロフィール情報などは、サービス提供のため、AWS（Amazon Web Services）のクラウドサービス等を利用して保存します。

一部の設定情報、未送信の位置記録データなどは、アプリがインストールされた端末内に保存される場合があります。通信状態によってはクラウドへの反映が遅れる場合があります。

情報の保存期間と削除方法については「9. 情報の保存期間と削除」をご確認ください。


## 5. 外部サービスの利用 【変更】

本アプリでは、サービス提供のために次の外部サービスを利用しています。

・AWS：ユーザー認証、データ保存、API等 ・RevenueCat：Premiumの購入状態および利用権限の確認 ・Apple App Store / Google Play：Premium商品の購入処理 ・Google Maps / Appleマップ：地図表示

これらのサービスでは、サービス提供に必要な情報が各事業者によって処理される場合があります。情報の取扱いには各事業者のプライバシーポリシー等が適用される場合があります。また、サービスのシステムやデータセンターの所在地により、情報が日本国外で処理または保存される場合があります。


## 6. Premium購入に関する情報 【変更】

Premium商品の購入処理はApple App Store / Google Playを通じて行われます。 本アプリがクレジットカード番号などの決済情報を直接取得することはありません。

本アプリでは、Premium機能を提供するため、 RevenueCatを通じて購入状態やPremium利用権限を確認します。


## 7. ユーザー間での情報共有 【変更】

【リアルタイム位置情報の共有】
ユーザーが位置共有の相手を選択し、共有を有効にした場合、現在地、取得・更新時刻などが共有相手に表示されます。アクティビティ履歴の共有とは別に、位置共有の設定を確認してください。

【アクティビティ履歴の共有】
グループへの参加だけで、過去のアクティビティ履歴が共有されることはありません。記録の所有者が、アクティビティ履歴ごとに共有相手と共有に使用するグループを指定します。共有されたアクティビティ履歴およびその地図・位置記録は、所有者と有効な共有権限を持つ相手が閲覧できます。アクティビティカレンダーには、ログイン中のユーザー本人が所有するアクティビティ履歴だけが表示されます。他のユーザーから共有されたアクティビティ履歴は、アクティビティカレンダーには表示されません。

共有解除、脱退、除外、グループの無効化・削除などによって対象の共有権限が失効すると、その相手は対象アクティビティ履歴や位置記録をサーバーから新たに取得できなくなります。ただし、別のグループを通じた有効な共有が残っている場合は、引き続き閲覧できます。グループへの再参加だけでは失効した共有は復活せず、所有者による再共有が必要です。記録の所有者本人の閲覧権限は、グループからの脱退・除外やグループ削除によって失われません。

【共有に伴う表示と注意】
「履歴の共有管理」画面や「共有グループ管理」画面などでは、相手を識別するために表示名、メールアドレス、プロフィール画像などを表示する場合があります。アクティビティランキングで表示される情報については「8. アクティビティランキング」をご確認ください。共有終了前に端末へ取得された情報や、共有相手が保存した画像・コピーまで消去できるとは限りません。

位置情報や移動履歴から自宅、勤務先、生活時間帯などが推測される場合があります。信頼できる相手と共有してください。他のユーザーから共有された情報を本人の同意なく第三者に公開しないでください。


## 8. アクティビティランキング 【変更】

アクティビティランキング機能では、表示名、プロフィール画像、対象となるアクティビティの移動距離、移動時間など、アクティビティランキング表示に必要な情報が、アクティビティランキングを閲覧できる他のユーザーに表示される場合があります。

アクティビティランキングには、本アプリが定める集計条件を満たすアクティビティのみが反映されます。操作説明用のサンプルアクティビティは集計対象になりません。


## 9. 情報の保存期間と削除 【変更】

ユーザー情報およびアクティビティ履歴は、原則としてアカウントまたは対象データが存在する間保存されます。

位置情報の取得権限は端末設定から変更・取り消しができます。これは今後の取得を制御する操作であり、保存済みアクティビティ履歴の削除とは異なります。記録の停止、共有の解除、保存済み情報の削除は、それぞれ対応する機能で行ってください。保存済みのアクティビティ履歴は、本アプリの「アクティビティ履歴」画面の「削除」機能から削除できます。

アカウント削除機能では、共有権限を失効させたうえで、位置記録、アクティビティ履歴、現在地情報、共有Grant、関連する共有操作情報、索引、月間・週次集計、記録診断情報、端末セッション、プロフィール画像、プロフィールおよび認証アカウントを順に削除します。ユーザーが所有する共有グループは削除し、他のグループからは脱退します。他のユーザーが所有するアクティビティ履歴は削除せず、対象となる共有権限を解除します。

この端末に保存された削除対象ユーザーの未送信記録も削除します。他のアカウントの未送信記録は削除しません。別の端末に保存された情報や共有相手が既に保存した画像・コピーまで、遠隔で消去できるとは限りません。

処理に時間がかかる場合は小分けにして進めます。通信断やアプリ終了などで中断した場合は、アカウント削除を再実行して続きから再開してください。エラーが表示された場合は、削除が完了したと判断せず、再実行するかお問い合わせください。

再開と重複実行防止のため、必要最小限の削除進捗情報を保持します。サーバー上の関連データの削除処理が完了した後、この進捗情報は7日を目安として自動削除処理の対象になります。

上記の記録診断情報とは別に、共有管理サーバーの共用運用ログには、処理時刻、ユーザー識別子、エラーなどが記録される場合があります。この共用運用ログは通常のアカウント削除の対象外です。現行の設定では保存期間の上限を設けていません。

法令により保持が必要な情報がある場合は、その目的に必要な範囲と期間に限って保持します。削除対象・方法・処理状況については「13. お問い合わせ」からご連絡ください。

## 1. 本アプリについて 【変更なし】

本アプリは、スマートフォン等の位置情報を利用して、 移動ルートやアクティビティを記録・確認・共有するためのサービスです。

本アプリには、FREEプランとPREMIUMプランがあります。


## 2. アカウント 【変更なし】

本アプリの利用には、アカウント登録が必要となります。 登録情報はメールアドレス、表示名、プロフィール画像などです。

ユーザーは、登録情報を適切に管理し、 自分のアカウントを第三者に不正に利用されないよう管理するものとします。


## 3. FREEプランとPREMIUMプラン 【変更なし】

FREEプランでは、本アプリの基本機能を無料で利用できます。 ただし、記録回数、記録時間、位置情報の記録条件、 共有グループ数などに一定の制限があります。

PREMIUMプランでは、FREEプランより細かな位置記録設定や、 制限が緩和された機能、 アクティビティ区分の変更などを利用できます。

各プランの具体的な機能および制限は、 アプリ内の「FREE / PREMIUM プラン」画面に表示します。


## 4. PREMIUMの購入 【変更なし】

PREMIUMは、現在、買い切り型の商品として提供しています。 定期的に料金が発生する自動更新型のサブスクリプションではありません。

購入価格は、購入時に各アプリストアに表示される 価格をご確認ください。

購入処理、支払方法、返金等については、 購入に利用したアプリストアの規約および 適用される法令に従います。

購入済みのPremium利用権限については、 アプリの「購入を復元」機能等により復元できる場合があります。

位置情報を利用する機能には、端末およびOSで必要な位置情報権限が許可されている必要があります。権限は端末の設定から変更できますが、権限を許可しない場合や取り消した場合は、位置記録や位置共有などの機能の一部または全部を利用できなくなる場合があります。


## 6. 位置情報の精度 【変更】

位置情報の取得精度、記録間隔、記録地点、移動距離などは、GPSの状態、端末、OS、通信状況、周辺環境、省電力設定などの影響を受けます。

このため、位置がずれる、記録が欠ける、実際とは異なる距離が表示される、情報の更新や共有に遅れが生じるといった事象が発生する場合があります。

アカウント削除機能では、共有権限を失効させたうえで、位置記録、アクティビティ履歴、現在地情報、共有Grant、関連する共有操作情報、索引、月間・週次集計、記録診断情報、端末セッション、プロフィール画像、プロフィールおよび認証アカウントを順に削除します。ユーザーが所有する共有グループは削除し、他のグループからは脱退します。他のユーザーが所有するアクティビティ履歴は削除せず、対象となる共有権限を解除します。

この端末に保存された削除対象ユーザーの未送信記録も削除します。他のアカウントの未送信記録は削除しません。別の端末に保存された情報や共有相手が既に保存した画像・コピーまで、遠隔で消去できるとは限りません。

処理に時間がかかる場合は小分けにして進めます。通信断やアプリ終了などで中断した場合は、アカウント削除を再実行して続きから再開してください。エラーが表示された場合は、削除が完了したと判断せず、再実行するかお問い合わせください。

再開と重複実行防止のため、必要最小限の削除進捗情報を保持します。サーバー上の関連データの削除処理が完了した後、この進捗情報は7日を目安として自動削除処理の対象になります。

共用のサーバー運用ログは通常のアカウント削除の対象外であり、現行の設定では保存期間の上限を設けていません。詳細はプライバシーポリシー「9. 情報の保存期間と削除」をご確認ください。

端末の位置情報権限を取り消しても、保存済みアクティビティ履歴は自動的には削除されません。情報の保存・削除については、プライバシーポリシー「9. 情報の保存期間と削除」もご確認ください。

Premium購入に関する取引記録は、各アプリストアなど購入処理を行う事業者側に残る場合があります。アカウント削除と購入の返金は別の手続きです。購入情報の管理・返金等は、各アプリストアの規約および適用される法令に従います。
