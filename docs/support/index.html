AcLog Fit について

AcLog Fit は、ウォーキングやランニングなどのアクティビティを 位置情報とともに記録し、移動ルート・距離・時間・消費カロリーなどを 振り返るためのアプリです。

よくある質問

位置情報が記録されません

端末の位置情報サービスが有効になっていることを確認してください。 バックグラウンド記録を利用する場合は、AcLog Fit の位置情報権限を 「常に許可」に設定してください。

iPhone: 設定 → プライバシーとセキュリティ → 位置情報サービス → AcLog Fit

バックグラウンドで記録されません

バックグラウンドでの位置情報利用が許可されているか確認してください。 また、端末の省電力設定やOSの動作状況により、位置情報の取得間隔が変化する場合があります。

記録されたルートに飛び値があります

GPSは、建物内・地下・高層ビル周辺・トンネルなどで精度が低下する場合があります。 そのため、実際の移動経路から外れた位置が記録されることがあります。

Premium の購入を復元したいです

アプリの「プロフィール」画面にある「購入を復元」をタップしてください。 同じApple IDで購入済みの場合、購入状態の復元を試みます。

機種変更後もデータを利用できますか？

同じAcLog Fitアカウントでログインすることで、クラウドに保存されているデータを利用できます。 端末内だけに残っている一時データや未送信データは引き継がれない場合があります。

お問い合わせ

不具合のご報告・ご要望・ご質問は、GitHub の Issues からお問い合わせください。

お問い合わせの際は、可能な範囲で以下を記載してください。

  • 端末名
  • OSバージョン
  • AcLog Fit のバージョン / Build番号
  • 発生した事象
  • 再現手順

プライバシー・アカウント削除

プライバシーポリシー アカウント・データ削除

アカウントを削除したい場合

AcLog Fit の「プロフィール」画面からアカウント削除を行うことができます。 アカウントを削除すると、位置履歴、アクティビティ履歴、プロフィール、 共有情報などの関連データが削除されます。

詳細は アカウント・データ削除ページ をご確認ください。
